# Proposed Information Architecture

This is a logical IA based on the current evidence and is not a redesign mandate. It reflects the site’s present structure and the likely user journey that should be supported.

## Current evidence-based structure
- Home
- Services / landing pages
- Pricing
- Work / portfolio
- About
- Hosting / support
- Insights
- Contact

## Proposed IA

### 1. Home / conversion hub
- Hero with proposition and clear CTA
- Service overview
- Proof section with verified client work and outcomes
- Pricing overview
- Process / how it works
- FAQ
- Final contact CTA

### 2. Services
- Web Design South Africa
- Web Development Johannesburg
- Ecommerce Website Design South Africa
- Website Hosting South Africa
- Website Maintenance
- SEO Web Design

Each service page should answer:
- what the service is
- who it is for
- what is included
- how it differs from alternatives
- what the next step is

### 3. Pricing
- Overview of packages
- Included features
- Support and hosting terms
- Renewal information
- “Which package is right for me?” helper
- CTA to enquire

### 4. Work / proof
- Verified client work only
- Case-study hub with outcome-based summaries
- Concept work kept separate and clearly labelled
- Each project should show: client, sector, project goal, what was delivered, and measurable outcome if available

### 5. About / company
- Company identity and founder or business story
- Why the business exists
- Process and partnership model
- Contact and access information

### 6. Support / hosting
- Hosting features
- Maintenance plans
- Support SLA and terms
- Renewal and leave policy if applicable

### 7. Insights
- Articles with practical value
- SEO and conversion guidance
- Website strategy and maintenance content

### 8. Contact
- Enquiry form
- WhatsApp CTA
- Email CTA
- Clear confirmation and “what happens next?”

## Strategic note
The structure is sound in principle, but it needs more proof and clearer commercial transparency. The current site is already on a strong conversion-path skeleton; the next step should be to tighten the evidence and clarify user decision points before deeper IA changes are made.
